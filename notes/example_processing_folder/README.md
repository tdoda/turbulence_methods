# example_processing_folder

This folder is an exmple folder containing lake Geneva Micro CTD data that can be used to test or try out the processing.

## How to use it


Move this folder out of your turbulence_method folder in a new folder and rename it 'field'. respect the following organisation:

            %  -- turbulence_methods
            %  -- field (previously called example_processing_folder from the notes in turbulence_methods)
            %  ------ data
            %  ---------- 2026081213
            %  -------------- Level0
            % -------------------- DAT_034.P
            % -------------------- SETUP.CFG
            % -------------------- Logbook_2026081213.xslx
            %  ------ processing
            %  ----------- analyze_profiles_local_2026081213_DAT_034.m
            
Once this is done, you should be able to run the script analyze_profiles_local_2026081213_DAT_034.m
